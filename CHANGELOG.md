# Changelog

## Versión 1.0, versión final 1

### Funciones de la versión

- Implementamos acceso con profesor, técnico y administrador.
- Gestionamos usuarios, ubicaciones y dispositivos con alta, edición, baja lógica y reactivación.
- Registramos tickets con asignación, prioridad, transiciones y seguimiento acumulativo.
- Documentamos incidentes de seguridad de forma manual, con acciones y conclusión al cerrar.
- Consultamos indicadores por rol e historial relacionado por equipo.
- Preparamos informes de tickets, incidentes e inventario para imprimir o guardar como PDF desde el navegador.

### Documentación y configuración

Incluimos la descripción del proyecto, arquitectura, modelo de datos, permisos, instalación y guía de lectura del código. La conexión se configura a partir de una plantilla y el SQL incluye datos ficticios con hashes pendientes de configurar localmente.
